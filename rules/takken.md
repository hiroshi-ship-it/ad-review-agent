# 規制モジュール：宅地建物取引業法・不動産の表示に関する公正競争規約

対象：一棟収益不動産の売買広告（類型③）、区分所有物件その他の宅建業としての広告（類型④）

現物不動産の売買・賃貸の広告として規制される。金融スキーム（信託受益権など）が絡む可能性があれば、先に売買の形態を確認し、`rules/fiea.md` の適用を判断する。

---

## 0. 最初に行う切り分け

適用法令の特定を誤ると、すべての指摘が崩れる。次の順で確定させる。

**① 用途**
専ら居住用 / 専ら事業用 / 住居兼事務所などの兼用 / 登記上の用途と実態が違う / 用途変更の予定がある

**② 表示規約が適用されるか**
- 表示規約にいう「建物」は主に居住用のもの。オフィスなど**専ら事業用の物件は、原則として表示規約の対象外**
- 居住用を含む物件、登記と実態が違う物件、用途変更を予定・訴求する物件、地区の公正取引協議会が別の運用を示している物件は個別に確認する
- **規約が適用されない場合、規約に由来する項目（徒歩分数の算出方法、必要な表示事項、「新築」「厳選」等の特定用語、二重価格など）を判定の根拠にしない。** 参考として触れる場合はその旨を明記する

**③ 一般消費者向けの表示に当たるか（景品表示法の適用）**
- 一般消費者が見られることだけでは決まらない。媒体とアクセス制限、配信対象、問い合わせの受付対象と申込フォームの項目、購入資格を事業者に限っているか、実際の販売先、を総合して実質的に判断する
- 個人か法人かだけで結論を出さない。個人でも賃貸事業として反復継続して取得するなら事業者の性質を持ち得る。逆に「事業者向け」と書いていても、個人への配信や個人名義での購入受付があれば一般消費者向けと評価され得る
- 判定は商品ライン・販売スキーム・広告の導線ごとに行い記録しておくと、個別の広告ではそれを使える。前提が大きく変わったら判定し直す
- **未判定の場合、景品表示法第5条を確定的な根拠にせず**「一般消費者向けの表示に当たる場合」と留保を付ける

**④ 条番号**
表示規約施行規則の条番号は改正で繰り上がっていることがある。古い資料を引用するときは現行の番号で確認する。

## 1. 一棟収益不動産（類型③）

**必ず表示する事項**
- 取引態様（売主 / 代理 / 媒介）。宅建業法第34条第1項。自ら貸主となる賃貸には同条の適用なし
- 商号・免許番号
- 所在地・用途・規模・価格（土地・建物・消費税の内訳）
- 建築年月・構造・階数・戸数（賃貸用の場合）
- 現況（入居中・空室・一部空室など）

（表示規約の適用がない事業用物件では、規約由来の項目は参考にとどめる）

**誇大広告の禁止**（宅建業法第32条）
- 所在、規模、形質、利用の制限、環境、交通その他の利便、代金、支払方法、ローンのあっせんについて、著しく事実に相違する表示、著しく優良・有利と誤認させる表示 → **RED**

**広告開始時期の制限**（宅建業法第33条）
- 開発許可・建築確認等の前の広告は禁止 → **RED**
- 既存物件の再販など許可等が不要なら対象外。適用の有無を先に判断する

**一棟収益物件に特有の点**
- **利回り**：表面（満室想定）か実質（現況ベース）かを明記する。表示する場合は、①1年間の予定賃料収入の取得価格に対する割合である旨、②予定賃料収入が確実に得られることを保証しない旨、③公租公課その他の費用を差し引く前である旨、を示す
- **現況と想定**：想定利回りと現況利回りが混在するならそれぞれ明示する
- **空室**：現況の空室率を示す。満室前提の利回りだけで実態を隠さない
- **耐震基準**：旧耐震（1981年5月31日以前の建築確認）か新耐震かを確認し、旧耐震なら明示する
- **建物状況調査**：実施済みなら結果の概要を示すことが望ましい（推奨）
- **大規模修繕**：直近の実施時期、修繕積立の状況（ある場合）
- **テナント**：業種、契約形態（普通・定期借家）、賃料改定条件、残存期間を確認し、有利な条件だけを強調しない
- **収支シミュレーション**：実際に使った主な前提条件とその根拠・出所を示し、前提が変われば結果も変わる旨を付ける。使っていない項目（現金購入モデルの金利、税引前モデルの税率など）を書く必要はない。返済額や収益効果を示さない単なる資金構成の例なら「計算例である旨」の注記で足りる

**おとり広告の禁止**
- 存在しない物件、成約済みなど取引できない物件、取引する意思のない物件の表示 → **RED**
- 成約・申込み・販売中止となった物件を、決めた頻度で削除・変更する運用（責任者、頻度、確認記録）を確認する
- 対象は広告主が管理できる範囲（自社サイト、自社アカウント、掲載契約のあるポータル）。第三者の転載や検索エンジンのキャッシュは、削除依頼の要否を判断すれば足りる

## 2. 区分所有物件・宅建業の広告（類型④）

### 2-1. 広告主・取引態様
- 「売主」「貸主」「代理」「媒介（仲介）」の用語で取引態様を示しているか（宅建業法第34条第1項）
- 広告主が有効な宅建業の免許を持っているか（宅建業法第12条）
- 商号、免許番号（規約適用時は所在地、電話番号、所属団体名、公正取引協議会の加盟事業者である旨も）
- 規約の対象外なら、広告主を特定できる表示（商号、連絡先等）があれば足りる。所在地がないことだけで不適合にしない

### 2-2. 表示基準（表示規約が適用される場合のみ）
- **徒歩○分**：道路距離80mにつき1分、端数切り上げ。建物の出入口から駅等の出入口まで。起点・着点を明示
- **交通機関の所要時間**：起点・着点の名称、種別（特急・急行等）、朝の通勤時間帯の所要時間。乗換えがあればその旨と乗換え時間を含めた時間
- **「新築」**：建築工事完了後1年未満**かつ**未使用
- **特定用語**（「厳選」「特選」「完全」「絶対」「日本一」「当社だけ」「抜群」「完売」等）：合理的な根拠資料が必要。最上級表現や著しく安い印象を与える用語は根拠となる事実の併記も必要
- **抽象表現**（「駅近」「好立地」等）：語の使用自体を一律に禁じるものではない。客観的な事実で説明でき、その広告か直接つながる物件ページで確認できればよい
- **二重価格**：過去の価格と比べる場合、公表日・値下げ日の明示、値下げ直前に2か月以上公表していた価格、値下げから6か月以内、物件の同一性など、すべての要件を満たすこと
- **写真・CG**：取引する物件のものを使う。他の物件のものを使うなら所定の要件と明示が必要。CG・完成予想図はその旨を明示

### 2-3. 投資用・収益に関する表示
- **利回り**：1節と同じ3点を示す
- **節税効果**：①不動産所得が赤字の場合に限り効果があり、黒字なら税額が増える旨、②必要経費が減れば効果も減る旨、③計算例は購入年度の翌年度以降のものを示す
- **賃料収入の保証**：保証する主体、内容、期間その他の条件を明示
- **転貸方式（マスターリース等）**：規約適用時は権利金、敷金、賃料、管理費、期間、更新・賃料改定などの条件を明示。規約非適用なら、訴求と切り離せない主な条件、すなわち(ア)賃料が固定・保証される方式か、(イ)実際のテナント賃料に連動する方式か、(ウ)賃料の減額や収入の変動があり得るか、を示せば足り、詳細は商品説明資料や契約書面で提供できる
- **管理の手間がかからない旨の訴求**：「一切不要」「すべてお任せ」等の包括的な表現は、実際に受託する範囲と合っているかを確認する。購入者が負担する費用（公租公課、保険料、管理費、修繕積立金など）があれば誤認を生じさせる
- **将来の価値・賃料収入の確実性**：合理的な根拠資料が必要。資料確認が未了ならYELLOW、削除で是正できるならBLUE、資料がなければ削除を求め、残すならRED
- **非保証の表示**：収益性・安全性・資産形成・賃料収入・ローン活用の効果・将来価値などを訴求する場合、「元本および収益を保証するものではありません」又は同等の表示を認識しやすい位置に置く。定型表示の追加で足りるなら **BLUE**。追加位置はページや箇所まで特定して指示する。包括的なリスク一覧は必須としない。提携ローンを紹介できる旨など、融資が使えることだけを書く場合は対象外

### 2-4. 区分所有建物に特有の点
- 専有面積が壁心か内法（登記簿）か：規約上の義務は新築分譲のパンフレット等に限られる。中古の広告での明示は推奨
- 管理費・修繕積立金の月額（規約適用時は必要な表示事項）
- 管理形態と管理員の勤務形態（規約適用時）
- 管理費等の滞納：広告に書いていないことは広告審査の対象外。ただし審査中に取引判断に大きく影響する事実を知った場合は取引の審査に引き継ぐ
- 区分所有法は広告の表示義務を定める法令ではない。用語の定義の参照にとどめ、判定の根拠にしない

### 2-5. サブリース規制（賃貸住宅の管理業務等の適正化に関する法律）
- 対象は**賃貸住宅**。専ら事業用の物件は原則対象外。住宅が混在する物件は判定して記録する
- 広告主が特定転貸事業者か、勧誘者か、どちらでもないかを、資本・提携関係、紹介料等の授受、マスターリースの内容説明、契約の勧め方などから判断する
- 該当する場合、家賃、支払期日、契約期間、解除、賃料減額の可能性などについて、著しく事実に相違する表示や著しく優良・有利と誤認させる表示は禁止（第28条）。打消し表示を付けても、全体から一般的な成果と受け取られる場合は違反となり得る
