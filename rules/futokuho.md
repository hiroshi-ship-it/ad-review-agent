# 規制モジュール：不動産特定共同事業法

対象：不動産特定共同事業の小口化商品（任意組合型・匿名組合型等）の広告（類型②）、特例事業（類型②'、`rules/fiea.md` と併用）、不動産クラウドファンディング（類型②''）

信託受益権の販売とは適用法令が異なるため、まずスキームを確認する。

---

## 1. 適用法令の整理

**原則：不特法第18条の広告規制が主たる根拠**

不特法の事業者の広告には、金商法第37条（広告等の規制）は原則として準用されない。不特法第21条の2が準用する金商法の規定は、第39条（損失補填等の禁止）と第40条（適合性の原則）に限られる。

**金商法との関係**

| 場面 | 整理 |
|---|---|
| 第1号事業者の自己募集（クラウドファンディング含む） | 不特法の契約に基づく権利は、金商法第2条第2項第5号ハによりみなし有価証券から除外されるため、金商法の登録は不要。ただし不特法上の電子取引業務の許可が別途必要 |
| 第4号事業者（特例事業の募集・私募の取扱い） | 特例事業の出資持分はみなし有価証券に当たり、第二種金融商品取引業の登録が必要 → `rules/fiea.md` |
| 行為規制 | 金商法第39条・第40条は全事業者に準用（不特法第21条の2） |
| 電子記録移転権利（セキュリティトークン等） | 一定の場合に有価証券の除外の対象外となり、金融商品取引業の登録が必要 |

## 2. 必ず表示する事項

（不特法第18条）【要確認：条項と施行規則の号の対応は最新の条文で確認すること】

- 許可番号・事業者名
- 事業の種別（第1号〜第4号事業）
- 元本割れのリスクがある旨
- 分配金が保証されない旨
- 中途解約の可否・条件

## 3. 虚偽・誇大表示が禁止される事項

（不特法第18条第3項、同法施行規則第37条）

| 号 | 事項 | 確認の要点 |
|---|---|---|
| 1 | 資力・信用 | 「上場企業グループ」「創業○年」等の信用の強調が実態と合っているか。上場しているのが事業者自身か親会社かを明確にしているか（主体の明示は一通りの訂正として **BLUE**） |
| 2 | 実績 | 運用実績等の根拠が示されているか。期間・対象を恣意的に抜き出していないか |
| 3 | 不動産取引の内容 | 所在・規模・用途等が正確か |
| 4 | 収益・利益 | 利回りの保証、「必ず○%」等の断定がないか。「想定」「目標」が明示されているか |
| 5 | 契約の解除 | 中途解約の可否・条件・解約時の負担が明記されているか |
| 6 | 損失の負担 | 損失時の負担関係が正確か。「元本は欠損しません」等の断定がないか |
| 7 | 市況 | 市況・賃料動向について断定や根拠のない表示がないか |
| 8 | 金銭の運用 | 運用方法・期間・手数料の概要が正確か |
| 9 | 特定電子権利の性質 | セキュリティトークン等を扱う場合のみ |
| 10 | 特定電子権利の保有・移転の仕組み | 同上 |

## 4. 書いていないことによる誤認

施行規則第37条は、各号の事項について**虚偽・誇大な表示を禁止**するもので、必ず書けという規定ではない。

ただし、その事項に一切触れないことで広告全体の印象が実態と食い違い、投資判断に重要な影響を与える場合は、「著しく人を誤認させるような表示」（不特法第18条第3項）として問題になり得る。

| 例 | 誤認のおそれ | 区分の目安 |
|---|---|---|
| 中途解約の可否・条件に一切触れていない | いつでも解約できると誤認させる | **YELLOW**〜**RED** |
| 損失の負担関係に一切触れていない | 損失を負わないと誤認させる | **RED** |
| リスクに触れず利益面だけを書いている | 利益が保証されていると誤認させる | **RED** |

決まった文言の注記を足せば誤認が解消するなら **BLUE** とし、包括的なリスク一覧の掲載を一律には求めない。

## 5. 小口化商品に特有の注意点

- 「現物不動産と同等の安定性」等の誤解を招く表示 → **YELLOW**〜**RED**
- 節税効果：相続税評価や所得税の効果を断定しない。個別の状況による旨を付ける
- 「プロが管理するから安心」等、管理を委ねることを過度に安全視させる表現 → **YELLOW**
- 優先劣後構造の説明で「元本は欠損しません」等と断定 → **RED**（不特法第21条の2による金商法第39条の準用）

## 6. 特例事業・第4号事業

`rules/fiea.md` の6節を参照。第4号事業か第3号事業かを最初に区別する。

## 7. 不動産クラウドファンディング（電子取引業務）

インターネット上で契約の申込みをさせる場合は、事業の号を問わず、国土交通省「不動産特定共同事業法の電子取引業務ガイドライン」に沿っているかを確認する。第4号事業（金商法適用）なら、`rules/fiea.md` 7節の電子募集規制も重ねて確認する。

**サイトでの商号等の表示**（電子取引業務ガイドライン5、施行規則第53条第1項）
- 会社名、許可番号、代表者氏名、業務管理者氏名、所在地、電話番号、事業の種別（電子取引業務を行う旨を含む）を、サイトの見やすい箇所に表示しているか
- 業務管理者名簿を、事業期間中、閲覧できる状態にしているか

**重要事項のウェブ閲覧**（施行規則第55条、ガイドライン10）
- 対象不動産の特定、取引態様、借入れの有無、価格と算定方法、鑑定評価、出資に関する事項、財産の分別管理、契約の解除・クーリング・オフ、報酬、予想される損失の要因、損失の負担と元本が保証されない旨、審査の概要と結果、電子取引業務として行う旨、照会先、利害関係などを、事業期間中、閲覧できる状態にしているか

**文字の大きさ**（ガイドライン10(2)）
- 損失の要因、損失の負担、権利義務の譲渡に関する事項を、それ以外の最も大きな文字と著しく異ならない大きさで表示しているか → 欠ければ **YELLOW**〜**RED**

**表示の順序**
- 重要事項を見やすい箇所に明瞭・正確に表示し、投資判断に重要な事項を先に示しているか

**クーリング・オフ**（ガイドライン8、施行規則第54条第3号）
- 契約成立時の書面を受け取った日から起算して8日を経過するまで解除できる旨を、契約前・契約時の書面に明記し、サイトでも表示しているか

**審査体制と審査結果の公表**（ガイドライン7、施行規則第54条第2号）
- 営業部門から独立した審査部門があるか（または合議体と管理部門責任者による確認）
- 財務状況・事業計画・資金使途・実在性等を審査し、概要と結果を公表しているか

**その他**
- 事業参加者への定期的な情報提供（施行規則第54条第4号）、金銭の預託を受ける場合の分別管理（施行規則第49条第2項）、システム管理（セキュリティ、誤操作防止、障害対応、他社サイトとの誤認防止）
