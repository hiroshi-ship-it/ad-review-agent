# ad-review-agent

**不動産・不動産金融の広告を、複数の法律で横断的にチェックするAIエージェント（Claudeのスキル）**

不動産クラウドファンディングや不動産ファンド、投資用マンションの広告には、金融商品取引法、不動産特定共同事業法、宅地建物取引業法、不動産の表示に関する公正競争規約、景品表示法などが重なってかかります。法律ごとに求められる表示も禁止される表現も違うため、1本の広告を見るにも複数の規制を行き来する必要があります。

このスキルは、広告原稿を受け取ると、

1. 商品の類型と、どの法律が適用されるかを最初に切り分け
2. 該当する規制モジュールだけを読み込んで問題箇所を洗い出し
3. 「直し方が一通りに決まるもの」と「直した後に改めて判断が要るもの」を分けて
4. 根拠と修正案をつけて返します

自社の広告審査基準を `company/` に置けば、それを最優先にして審査します。

> **注意**
> このスキルは広告審査の**判断を支援する道具**であり、法的な判断を確定させるものではありません。掲載の可否は、広告主の審査担当者または弁護士等の専門家が判断してください。
> 法令・ガイドラインは改正されます。条番号や要件は利用時点の最新版で確認してください。

## 構成

```
ad-review-agent/
├── SKILL.md                  審査の進め方、トリアージの枠組み、出力の形
├── rules/                    規制モジュール（必要なものだけ読み込む）
│   ├── fiea.md                 金融商品取引法（信託受益権、第4号事業、電子募集）
│   ├── futokuho.md             不動産特定共同事業法（小口化商品、クラウドファンディング）
│   ├── takken.md               宅建業法・表示規約（一棟収益、区分所有）
│   └── common.md               景品表示法、ステマ、著作権・肖像権、お客様の声、媒体
├── company/
│   └── standards.example.md  自社基準の記入例
├── samples/                  審査デモ用の架空広告
└── examples/                 審査結果の例
```

## 対応している広告の類型

| 類型 | 主な法令 |
|---|---|
| 不動産信託受益権の販売 | 金融商品取引法、二種業協会規則・ガイドライン |
| 不動産特定共同事業の小口化商品 | 不動産特定共同事業法 |
| 特例事業・第4号事業 | 不特法＋金融商品取引法 |
| 不動産クラウドファンディング | 不特法・電子取引業務ガイドライン（＋電子募集規制） |
| 一棟収益不動産の売買 | 宅建業法、表示規約 |
| 区分所有物件・宅建業の広告 | 宅建業法、表示規約、景品表示法 |

## 使い方

### Claude（claude.ai / デスクトップアプリ）で使う

1. このリポジトリをダウンロードし、フォルダごとスキルとして追加します
2. 広告原稿（テキスト、PDF、画像、スライド）を渡して「この広告を審査して」と頼みます

### Claude Code で使う

```bash
git clone https://github.com/hiroshi-ship-it/ad-review-agent.git ~/.claude/skills/ad-review-agent
```

### 自社基準を使う

`company/standards.example.md` をコピーして `company/standards.md` を作り、自社の判定区分・上乗せ基準・チェックリストを書き込みます。
`.gitignore` で `company/` 配下（記入例を除く）はコミットされないようになっています。

## 設計の考え方

- **適用法令の切り分けを最初に行う**：用途、表示規約の適用の有無、一般消費者向けかどうかを先に確定させないと、以降の指摘がすべてずれます
- **規制はモジュールに分ける**：類型に関係ないルールは読み込まないので、判断がぶれにくく、新しい規制も足しやすくなります
- **訴求はできるだけ残す**：表現が強いだけでは指摘せず、削除の前に「範囲を絞る」「言い切りを和らげる」「根拠の事実を添える」「注記を付ける」で直せないかを先に検討し、修正後の文案まで示します
- **直し方が一通りか、判断が要るか**で分ける：「削除すれば最短で掲載に進める／残すなら再審査」と選択肢で示し、事業部門が自分で方針を選べるようにしています
- **分からないことは【要確認】と書く**：もっともらしく埋めることはしません
- **法令上の義務と推奨を区別する**：「念のため」で必須表示を増やしません
